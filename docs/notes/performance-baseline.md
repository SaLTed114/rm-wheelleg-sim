# 第一轮 MuJoCo 性能基线

## 环境与方法

- 日期：2026-08-02。
- Windows、MSVC 19.44、Windows SDK 10.0.26100、MuJoCo 3.9.0。
- MuJoCo 物理周期与控制周期均为 `1 ms`。
- 每个档位独立 reset，关闭输出沉降 2 秒，进入
  `BALANCE_ENGAGING` 后再静止收敛 2 秒，然后升速、保持 3 秒、
  斜坡刹停并观察 2 秒。
- 直行粗扫 `+/-1, 2, 3 m/s`，原地旋转粗扫
  `+/-pi, 2*pi, 3*pi, 4*pi rad/s`。
- 稳定、跟踪、刹停和饱和分别分类；原始数据位于本地忽略目录
  `build/performance/initial/summary.csv` 与 `trace.csv`。

稳定要求所有数据有限、腿长处于 `0.13-0.20 m`、双轮接触率至少
99%、无其他部件触地且最大 roll/pitch 小于 10 度。跟踪要求保持阶段
末 1 秒的平均误差和 RMSE 均小于目标的 10%，并分别采用
`0.10 m/s`、`0.20 rad/s` 的最小容差。任意非轮部件触地都会立即终止
当前案例，但不会阻止后续档位从干净状态继续执行。

## 首轮结果

| 案例 | 稳定 | 跟踪 | 刹停 | 主要结果 |
| --- | --- | --- | --- | --- |
| `+1 m/s` | 是 | 是 | 否 | 平均误差 `+0.0259 m/s`，RMSE `0.0296 m/s`，最大 pitch `3.94 deg` |
| `-1 m/s` | 是 | 是 | 否 | 平均误差 `-0.0263 m/s`，RMSE `0.0301 m/s`，最大 pitch `4.69 deg` |
| `+2/+3 m/s` | 否 | 未完成 | 未完成 | 同一加速轨迹上底盘首先触地，最后一个 100 Hz 样本的参考速度约 `1.64 m/s` |
| `-2 m/s` | 否 | 已达到末段跟踪窗口 | 未完成 | 跟踪误差较小，但在刹停斜坡中底盘触地 |
| `-3 m/s` | 否 | 未完成 | 未完成 | 加速阶段右后腿触地，最后一个样本参考速度约 `-2.44 m/s` |
| `+/-pi rad/s` | 否 | 未完成 | 未完成 | 保持初段底盘触地，双轮接触率降至约 `0.87-0.90` |
| `+/-2pi` 至 `+/-4pi rad/s` | 否 | 未完成 | 未完成 | 均在相同斜坡前段触地，未到达各自目标 |

`+/-1 m/s` 全程双轮接触且没有执行器饱和，最大 roll 小于
`0.46 deg`。刹停观察末 1 秒仍有约 `0.132-0.133 m/s` 的反向平均速度，
RMSE 约 `0.141 m/s`，因此没有满足当前刹停线。

原地旋转从 `pi rad/s` 档开始已经出现轮力矩限幅：限幅前单轮峰值约
`7.5-11.5 N*m`，单轮饱和时间比例约 3% 至 11%。更高档在参考偏航速度约
`4.47-4.92 rad/s` 时已经触地，因此 `2pi/3pi/4pi` 案例在失效前具有
相同轨迹。触地前关节限幅未触发，观测到的关节请求峰值最高约
`33.6 N*m`。轮子失去稳定接触后，纯轮速里程计给出了约
`6-8 m/s` 的虚假前进速度，这与当前尚未融合接触状态的已知限制一致。

## 当前结论

- 本次粗扫确认的双向稳定且可跟踪直行档位为 `1 m/s`；真实边界位于
  `1-2 m/s` 之间，并且正反向失效阶段并不完全对称。
- 本次没有任何粗扫 yaw 档通过；这不表示稳定上限为零，因为现有回归
  已验证 `+/-1.57 rad/s` 能运行。当前 yaw 边界位于 `1.57 rad/s` 与
  `pi rad/s` 之间。
- 当前首要限制表现为离地/触地后的几何和观测问题，以及 yaw 通道的轮
  力矩饱和；第一轮数据不足以单独归因于 LQR 增益、模型参数或缺少 roll
  补偿。
- 下一轮应在上述两个区间内细扫，并结合 trace 检查底盘离地间隙、轮地
  接触、轮速里程计和 LQR 原始请求；在完成归因前不调整控制参数。
